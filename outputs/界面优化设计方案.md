# 幕间（MuJian）· 界面优化设计方案

> 目标：在保留现有「朱砂红 + 暖纸灰 + 鎏金评分」戏曲气质的前提下，针对信息架构、卡片密度、视觉层级、易用性做一次**完善型优化**，做到「既美观又易用、符合用户习惯」。
> 配套可交互原型：
> - `outputs/mujian-redesign.html`（导航/首页/卡片/详情的 before-after，桌面视角）
> - `outputs/mujian-mobile.html`（**移动端专题**：首页 + 编辑详情页，含「更多」下拉、通用筛选面板、双列编辑页）

---

## 0. 设计原则

1. **保留品牌资产**：不颠覆现有视觉语言，只修正体验摩擦点。
2. **减负优先**：能一眼看懂的，不藏进二级菜单；次要功能折叠而非删除。
3. **列表即主场景**：卡片要「远看有重点、近看有细节」。
4. **跨端一致心智**：桌面与移动共用同一套交互（快捷筛选=胶囊、操作=常驻入口）。
5. **无障碍与动效默认到位**：键盘可达、对比达标、`prefers-reduced-motion` 兜底。

---

## 1. 现状评估

**已做得好**
- 统一令牌体系 + 明暗双主题，品牌气质鲜明。
- 卡片海报 + 多角标信息丰富；编辑表单的胶囊输入 / 拖拽排序 / 自动定位体验扎实。
- 动效克制（fadeUp / stagger / shimmer 骨架屏），微交互用心（定位到当前时间、封面灯箱、自动补全）。

**可优化点**
- 顶栏 **10 个导航项平铺**，次级功能（封面/分类/数据）与核心功能同级，认知负担重。
- 演出卡片**四角角标偏拥挤**（剧种 / 状态 / 评分 / 选择），信息互相打架。
- 首页搜索 + 筛选 + 批量 + 新建挤在一行，Hero 不聚焦。
- 筛选藏在**底部弹层**，桌面端不如常驻快捷筛选顺手。
- 详情页折子「胶囊 + 顿号链接」混排，略混乱。
- 缺全局可见的**主题切换**与**首屏数据概览**。

---

## 2. 信息架构 · 导航重组

**方案（落地首选，改动最小）**
- 常驻主场景 4 个：`记录 / 剧目 / 演员 / 日历`。
- 其余收进「**更多 ▾**」下拉：`分析 / 地图 / 封面 / 分类 / 数据 / 设置`。
- **移动端不再使用抽屉**：因菜单已缩减为「4 主标签 + 更多」，顶栏直接以「更多 ▾」下拉收纳全部次级功能（含设置），省去抽屉这一层交互；桌面端同理以顶栏「更多」呈现，次级入口不再平铺。

**备选（后续升级）**：桌面**左侧常驻栏**（个人数据库型工具更贴合习惯，滚动不丢导航），窄屏自动收为抽屉，与现有移动方案一致。

---

## 3. 首页 / 列表 · 聚焦 Hero 与快捷筛选

- **搜索框成为视觉主角**（更大的胶囊、更克制的装饰），右侧仅留「筛选」「＋ 新建记录」两个常驻动作。
- **快捷筛选重评估（关键修正）**：移除了上一版里硬编码的「`📍 上海`」单点城市胶囊——它只对去过上海的用户有意义，换个用户就毫无用处，且「想过滤其他城市怎么办」无从回答。
  - **快捷行只保留人人适用的「剧种维度」**：`全部 / 昆剧 / 京剧 / 越剧 / 黄梅戏 / 话剧`，横向滚动。
  - **城市 / 时间 / 评分 / 状态统一收进「筛选」面板**（移动端为底部抽屉），城市改为**自由文本输入**——想过滤哪个城市就填哪个，不再有专属胶囊。这样任意城市都可过滤，且快捷行不被偶发维度污染。
- **首屏轻量数据概览**（可选增强）：`总记录 / 本年度 / 走过城市 / 平均评分` 一行小卡，让空列表也有归属感与引导。
- 列表标题保留「记录 N」与排序入口。

---

## 4. 演出卡片 · 去拥挤

- 四角角标 → **仅保留「剧种 + 评分」**两项（左上剧种、右下评分），海报不再被切割。
- **间距放宽、布局不拥挤**：网格间距由 16px 提至 18px，卡内边距同步加大，封面比例略收（约 1:1.38）以压低卡片高度；移动端双列也保持呼吸感。
- **状态 / 剧团下沉**到信息区：状态并入 meta 行（`日期 · 城市 · 场馆`），剧团仅在「想看/未赴约」等需要强调时出现。
- 信息层级：`剧名（衬线 2 行截断）→ 日期·城市·场馆 → 主演`（演员超 3 人显示「等」）。
- 选择态（批量模式）沿用现有右下圆形勾选，不新增角标。

---

## 5. 演出详情 · 结构化重组

- **折子按剧目聚合成簇**：`《剧名》→ 折子1 / 折子2`，告别顿号链接混排。
- 信息分卡：`剧目·折子` / `演出信息` / `费用`（票价/实付/合计/渠道）/ `备注`。
- 关键字段（票价、实付、合计）以 KV 表右对齐，合计加粗分隔线。
- 可选增强：同剧目 / 同演员的「相关记录」推荐区。

---

## 6. 设计令牌微调建议（向后兼容）

| 维度 | 现状 | 建议 |
|---|---|---|
| 区块标题 | `h3` 15.5–16px，权重/色不一 | 抽 `.section-title` 统一 16px / `var(--text-2)` / 可选「查看全部」 |
| 圆角 | 12–16px 混用 | 收敛为 `--radius`（12–14）主导卡，`--radius-lg`（18）仅大卡/弹层 |
| 焦点环 | 部分用 accent、部分默认 | 统一 `:focus-visible { outline: 2px solid accent; offset: 2px }` |
| 弱文本 | `--text-3` 用于提示 | 仅用于装饰性提示，重要说明改用 `--text-muted` 保对比 |
| 动效 | 已有但无降级 | 加 `@media (prefers-reduced-motion: reduce)` 关闭位移/缩放 |
| 主题 | 上一版保留全局切换按钮 | **移除全局切换**：默认 `prefers-color-scheme` 自动主题，已内置明/暗两套令牌，无需手动入口 |

---

## 7. 无障碍 & 动效（默认到位）

- 全站 `focus-visible` 焦点环；交互元素 ≥ 44px 触控区。
- 胶囊/下拉/按钮均带 `aria-label` 与键盘可达（现有已较好，补「更多」菜单）。
- 动画统一走 `--ease` 与 `--t-*`，并尊重 `prefers-reduced-motion`。

---

## 8. 落地优先级（建议）

1. **P0 导航重组 + Hero/快捷筛选**（感知最强、风险最低、纯前端）。
2. **P0 演出卡片去拥挤**（列表主场景，直接提升每日浏览体验）。
3. **P1 详情页折子聚合 + 费用分卡**（结构化，改动集中在详情页）。
4. **P1 令牌微调 + 自动主题收口**（移除全局切换按钮，改用 `prefers-color-scheme`）。
5. **P2 首屏数据概览 / 相关记录推荐**（增强，可后置）。
6. **P2 移动端专项**：导航「更多」下拉、通用筛选面板、双列编辑页视觉提纯（见第 9 节）。

> 所有改动均建立在现有 `app.css` 令牌之上，建议以「组件级增量升级」方式并入，不重写页面。

---

## 9. 本次移动端专项（首页 + 编辑详情页）

> 依据最新反馈所做的专项优化，原型见 `outputs/mujian-mobile.html`。

### 9.1 移动端首页
| 决策点 | 优化 |
|---|---|
| 导航 | **放弃抽屉**，顶栏常驻 4 主标签（记录/剧目/演员/日历）+「更多 ▾」下拉收纳次级（分析/地图/封面/分类/数据/设置）。少一层交互，认知更轻。 |
| 主题 | **移除全局切换按钮**，默认跟随系统 `prefers-color-scheme`，原型内置明/暗两套令牌自动切换。 |
| 快捷筛选 | 删除硬编码的「上海」单点城市胶囊；快捷行仅留**剧种维度**（全部/昆剧/京剧/越剧/黄梅戏/话剧）。城市改为筛选面板内的自由文本——**任意城市都可过滤**。 |
| 筛选面板 | 底部抽屉，含 `时间 / 评分 / 状态 / 城市` 四组通用维度，城市中可填任意值。 |
| 卡片 | 网格间距 18px、卡内边距加大、封面仅「剧种+评分」两枚徽章，布局宽松不拥挤。 |

### 9.2 编辑详情页（保留双列提取效率）
- **结构不动**：仍为「左列表单主体（基本信息/观演信息/费用与渠道/阵容）+ 右列备注+封面」，桌面 `≥860pt` 双列并排、右列粘性，输入备注时左列剧目/折子/演员同屏可见，避免上下翻屏。
- **视觉提纯**：
  - 区块标题统一为「朱砂色标 + 16px」样式，层级清晰一致。
  - 输入框统一聚焦环（accent + 柔光），`surface-2` 底色、聚焦转 `surface`。
  - 演员/剧团胶囊：已关联=朱砂柔底，自由文本=中性底描边，配 grip 与移除键。
  - 星级用鎏金；折子选择器选中态填充朱砂柔底。
  - 剧目卡片带剧名+剧种标签+折子网格，内联「＋添加折子」。
- **移动端**：窄屏下双列自动堆叠为单列（`.phone-edit` 覆盖 `flex-direction`），区块标题样式保持一致。

### 9.3 落地注意
- 移动端「更多」下拉与桌面「更多」共用同一组件，仅触发方式不同（顶栏点击 vs 抽屉按钮）。
- 筛选面板在移动端=底部抽屉、桌面端=右侧/顶部下拉，过滤状态共享。
- 编辑页双列逻辑已存在于 `RecordForm.svelte`（`@media (min-width: 860px)` 双列 + 右列 sticky + ResizeObserver 让备注框等高），本次仅做样式提纯，不改交互骨架。
