# 货殖账单关联（Huozhi）

幕间可与自建记账系统「货殖」打通：每条演出记录可绑定一个或多个货殖账单 ID，详情页据此展示费用，并优先采用货殖接口返回的金额而非记录内建的费用字段。

- 项目主页：<https://github.com/Felix2yu/huozhi>

## 配置

在「设置 → 货殖账单关联」中开启并填写：

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 启用 | 总开关 | 关 |
| 域名 | 货殖实例地址，如 `https://huozhi.example.com` | — |
| API Key | 货殖 `X-API-Key`，用于读取账单 | — |
| 账单路径 | 账单页路径模板，`{id}` 会被替换为账单 ID | `/bills/{id}` |
| 门票分类关键词 | 逗号分隔；账单分类含任一关键词则归「门票实付」，否则归「其他开销」 | `娱乐,演出,门票,戏,剧,综艺,电影,演唱会,音乐会,话剧,曲艺,相声` |

上述设置同时可由环境变量注入（环境变量优先级高于设置页保存值）：

| 环境变量 | 对应设置 | 默认值 |
|----------|----------|--------|
| `HUOZHI_ENABLED` | 启用 | `false` |
| `HUOZHI_DOMAIN` | 域名 | — |
| `HUOZHI_API_KEY` | API Key | — |
| `HUOZHI_BILL_PATH` | 账单路径 | `/bills/{id}` |
| `HUOZHI_TICKET_CATEGORIES` | 门票分类关键词 | 见上 |

配置读取顺序：**环境变量 → `settings.json` 持久化值（设置页保存）**。API Key 在 `GET /api/settings` 返回中以掩码呈现（如 `sk-…****`）；保存时若未改动则不回传该字段，避免把掩码当作真实密钥写回（后端亦会兜底忽略）。

## 绑定账单

- 在演出「新建 / 编辑」表单中填写货殖账单 ID（多个以逗号分隔）。
- 保存后写入该记录的 `huozhi_bill_ids` 字段。
- 历史演出不做回溯关联，仅可在编辑时手动绑定。

## 费用展示与分类

详情页费用区按关联账单展示：

- **门票实付**：分类命中关键词的账单小计。
- **其他开销**：其余账单（交通、酒店等）小计。
- **合计**：两类之和；当账单币种不一致时直接相加，并在界面提示「币种不一致，已直接相加」。
- 悬停单笔账单显示描述 / 账户 / 商户等明细，点击跳转货殖账单页。

分类规则（`ClassifyBillRole`）：

1. 账单 `category` 为空 → 归「门票实付」（关联货殖的主要动机是票款）。
2. `category` 包含任一关键词（子串匹配、大小写不敏感）→ 归「门票实付」。
3. 其余 → 归「其他开销」。可在货殖侧为账单显式设置分类（如 `交通` / `酒店`）来归入其他开销。

**金额优先级**：当某演出关联了可用账单时，详情页优先展示货殖合计金额，而非记录内建的费用字段。

## API

所有接口前缀 `/api`：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/records/{id}/bills` | 解析该演出关联的货殖账单，返回 `bills` / `total` / `currency` / `mixed_currency` / `breakdown` / `effective_source`（`huozhi` 或 `local`） |
| POST | `/huozhi/bills` | 表单保存前批量预览，请求体 `{"ids":[...]}`，返回同上结构 |
| POST | `/settings/test-huozhi` | 校验货殖配置；可带 `bill_id` 真实拉取一次账单验证连通性 |

`breakdown` 为按角色分组的小计数组（`role` / `label` / `total` / `currency` / `mixed_currency` / `bills`），与详情页展示口径一致；`total` 字段保留以兼容旧调用方。

后端对账单查询做 **60 秒** 缓存（按域名 + 账单 ID 缓存，上限 512 条），降低对货殖实例的请求压力。

## 货殖接口约定

幕间以 `GET {域名}/api/public/bills/{id}` 读取账单，请求头带 `X-API-Key: {API Key}`，期望响应信封：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 123,
    "description": "……",
    "amount": 11,
    "currency": "CNY",
    "type": "expense",
    "tx_date": "……",
    "merchant": "",
    "remark": ""
  }
}
```

账单字段容错解析：`amount` 可为数字或字符串，`account` 可为字符串或对象（统一压平为字符串）；无法识别的形态降级为空值，而非让整条记录解析失败。

## 常见问题

- **设置页一直加载 / 报 `Can't find variable: id`**：通常是前端把提示文本或 `placeholder` 中的花括号当成了模板插值。货殖相关文案与账单路径占位符均已避免裸花括号——路径模板 `/bills/{id}` 中的 `{id}` 由后端替换，不是 Svelte 插值。
- **金额不显示 / 仍显示本地费用**：确认已开启货殖、域名与 API Key 正确，且演出已绑定有效账单 ID；可在设置页「测试连接」并填入一个真实账单 ID 验证。
- **一笔开销被算进门票实付**：在货殖侧为该账单设置具体分类（如 `交通`），或调整设置页「门票分类关键词」使其不再命中。
